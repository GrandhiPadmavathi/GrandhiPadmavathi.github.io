SafeOps Agent

A tool-using LLM agent for e-commerce order support and banking operations. Lookups run freely, but every refund, cancellation, card block or reversal pauses for a human reviewer. A dry-run check rejects rule-breaking requests before anyone is interrupted, and every decision lands in an audit log.

  • 0 unsafe executions across 40 scenarios, including prompt-injection attacks
  • Dry-run policy check cut reviewer interruptions from 19 to 12
  • Same tools served to Claude Desktop / Cursor through an MCP server

RAG · LLM evaluation

Document Chatbot

Ask questions about your PDFs, Word files and spreadsheets and get answers with citations. Hybrid search (keyword BM25 + meaning-based vectors, merged with Reciprocal Rank Fusion), optional cross-encoder re-ranking, and a strict prompt that refuses rather than guesses.

  • Hit@5 0.92, MRR 0.92 with re-ranking on a 26-question evaluation set
  • Found and documented a trade-off: re-ranking improved ranking but weakened one refusal
  • Runs fully local (Ollama) or as a hosted demo (Groq + Hugging Face)

Machine learning · Data science · MLOps

Credit Risk Scoring

A credit default model on 30,000 customers, built the way a lender needs it: SQL features in DuckDB, a calibrated LightGBM model with common-sense constraints, an approval cut-off chosen by money, not accuracy, plain-English reasons for every decision, a fairness audit, and drift monitoring.

  • AUC 0.788, beating logistic regression by +0.017 (bootstrap-verified)
  • Profit-optimal policy: +NT$9.6M vs −NT$4.2M with the usual 0.5 cut-off
  • Fairness audit with a proxy ablation, reported openly in a model card
